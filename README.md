# デイリー・ヒーロー・インタビュー（DHI）

1日を振り返るための、気軽に続けられる簡易日記アプリです。  
毎日ランダムで表示される質問に答えるだけで、  
「今日を言葉にする」習慣を作ることができます。

---

## 特徴

- 毎日ランダムで「今日の質問」を表示
- 最大3問まで質問を追加可能  
  - 1問目：今日を振り返る質問  
  - 2問目：明日や近未来を考える質問  
  - 3問目：価値観・雑談系の質問
- 入力内容はブラウザに自動保存（localStorage）
- 過去の日付の記録を一覧・閲覧可能
- スマホでも使いやすいシンプルなUI

---

## 使い方

### 今日の質問に答える
1. トップ画面で「今日の質問」が表示されます
2. 回答を入力します
3. 必要に応じて「質問を増やす」で質問を追加
4. 「保存」を押すと、その日の記録が保存されます

### 過去の記録を見る
1. 画面上部の「履歴」タブを選択
2. 日付一覧から見たい日をタップ
3. その日の質問と回答を確認できます

---

## データの保存について

- 回答内容は **各端末のブラウザの localStorage** に保存されます
- アカウント登録やログインは不要です
- 他の人のデータが見えることはありません

## 注意  
- ブラウザのデータ削除や端末変更を行うと、記録は消えます
